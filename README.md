# Сайт «Земельный Сервис» v2.0

**Дата:** 2026-05-11
**Заявитель:** `КОМПАНИЯ "ЗС"` (временное обозначение, до регистрации юр.лица).
**Назначение:** публичный сайт проекта для пользователей и инвесторов + интерактивный прототип мобильного приложения.
**Основание переработки:** правки 10 экспертов универсальной экспертизы (Engagement reference: EX-2026-05-11-ZEMSERVIS-001).

## Что изменилось vs v1.0

### Тарифы (полная переработка по правке E2 — LegalTech / B2C)
- v1.0: «Самостоятельно / С юристом» → v2.0: **«Диагностика (бесплатно) / Pre-litigation (50–80 тыс ₽) / Полное представительство (150–300 тыс ₽)»**.
- Привязка к value, а не к жанру (правка E2: «Базовый/Стандарт/Премиум — взято из консьюмерского LegalTech, который умер»).

### SLA в маркетинге (правка E4 — UX 45–65)
- v1.0: «План действий за 15 минут» → v2.0: **«План действий за 24 часа»**.
- «10 минут» остаётся внутренним амбициозным таргетом, но не обещанием.

### Регионы (правка E8 — региональный аналитик)
- v1.0: «7 регионов московского кластера» → v2.0: **3 региона на старте (Тверская + Ярославская + Калужская)** → Phase 2 экспансия до 6 регионов.
- Московская обл. и ТиНАО — отложены в **Phase 3** (рынок закрыт через перевод категорий).

### KPI (правка E5 — CFO)
- v1.0: «GMV ₽50M/мес к М8» → v2.0: **«₽15M GMV/мес к M10, 100 платных кейсов, 3 региона, LOI на Series A»**.
- Hockey-stick переписан на защитимые цели.

### Valuation (правка E6 + E10)
- v1.0: Mid ₽30M / High ₽45M → v2.0: **Mid ₽25–28M / High ₽35–38M / post-DD ₽18–22M**.
- Применён Lack of Key Person Discount (Bus-factor 1) и регуляторный риск в Bear-сценарии.

### Делегированная роль (правка E4)
- Добавлен **Сценарий 3** на странице «Как работает» — отдельный путь для родственника, ведущего дело за пожилого собственника.
- В М2 Lean, а не «когда-нибудь потом».

### Антифрод (правка E7 — Compliance)
- Добавлен раздел «Антифрод с релиза, а не с М6».
- Cooling period 48 ч (для 70+ — 72 ч), проверка иска через ГАС «Правосудие» (открытое API), лимит на первую сделку, ОРИ-реестр (ФЗ-149).

### Compliance map (правка E10 — Big-4 аудитор)
- Добавлены **ФЗ-149** (ОРИ-реестр), **ФЗ-187** (КИИ), **63-ФЗ ст.5** (уровни ЭП), **ГК ст.1005** (агентский договор — почему не комиссионер).

### Команда (правка E7)
- Добавлены **Compliance Officer (FT)** и **Fraud Lead (FT)** — без них штраф ₽500M по ФЗ-420 — экзистенциальный риск.

### Голосовой ввод кадастра (правка E4)
- **Убран** из сценария «Добавить участок». STT WER 8–15% на длинных числах — пенсионер 70 лет не исправит. Заменён поиском по адресу через dadata.

### Каналы уведомлений (правка E4)
- **СМС — первичный канал** (открываются 60–80% у 65+ vs push 12–18%).
- Push — вспомогательный.

## Что НЕ изменилось

- Концепция wedge B-3 «Спасение от изъятия» по 101-ФЗ.
- Региональные данные (Россельхознадзор Тверской 4 310 нарушений, Ярославская 400 тыс. га, Калужская 9 участков изъято).
- 7 стратегий устранения признаков (S-1..S-7).
- Технологический стек (Yandex Cloud, Postgres Pro 17, React Native, YandexGPT 5.1 Pro / GigaChat 2).
- Юр-каркас (оферта, политика ПДн, согласие, ПЭП-соглашение).
- Английская/французская/арабская версии — оставлены без правок текста (правки v2.0 пройдут в локализованных версиях после согласования RU-версии владельцем).

## Что осталось вне моего контроля (Блок A — действия владельца)

В переработку v2.0 НЕ включены пункты, требующие действий владельца:
- 30 customer-dev интервью с пайщиками Тверской и Ярославской.
- Меморандум по ст.170 ГК у профильного юриста.
- Регистрация юр.лица.
- Подача заявки в Роспатент.
- LOI с банком-партнёром и Parser-API/Контур.Реестро.
- Со-фаундер с земельно-юр опытом.

## Технологии

- Чистый HTML5 + CSS3 + Vanilla JS — без фреймворков, для портативности и скорости.
- Mobile-first; брейкпоинты 640 / 768 / 1024 / 1280.
- WCAG 2.1 AA: контраст ≥ 4.5:1 для текста, focus-visible, aria-labels, semantic HTML.
- 0 внешних шрифтов / 0 трекинга — приватность по 152-ФЗ.
