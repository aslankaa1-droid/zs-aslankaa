## Технологии

- Чистый HTML5 + CSS3 + Vanilla JS — без фреймворков, для портативности и скорости.
- Mobile-first; брейкпоинты 640 / 768 / 1024 / 1280.
- WCAG 2.1 AA: контраст ≥ 4.5:1 для текста, focus-visible, aria-labels, semantic HTML.
- 0 внешних шрифтов / 0 трекинга — приватность по 152-ФЗ.
- Тёмная тема через CSS variables и `prefers-color-scheme`.

## Деплой

Сайт — статический, разворачивается на любом веб-сервере или CDN. Кандидат для прода — Yandex Object Storage + Yandex Cloud CDN или Caddy на Yandex Cloud VM.

Адрес домена — `zemelny-service.ru` (свободен, см. `15_research/v1.0/domain_check_v1.0.md`). Регистрация — после выбора правовой формы заявителя.

## Что нельзя использовать

- Сбор email на лендинге **до** уведомления РКН об операторе ПДн.
- Внешние SDK с трекингом (Google Analytics, Yandex Metrica с ПДн-конфигом без согласия).
- Сторонние шрифты с CDN (внешний домен → ПДн в логах).

Форма обратной связи на `contacts.html` помечена как «активируется после регистрации юр.лица» — до этого выводится `mailto:aslankaa@yandex.ru`.
