О нас

Делаем доступной защиту земли

Земельный Сервис — российский RegTech-проект, помогающий собственникам земельных участков навигировать сложности 101-ФЗ и других земельных законов. Без юридического жаргона. С российскими технологиями. По законам Российской Федерации.

Миссия

Каждый собственник земли должен понимать, что с его участком происходит и что с этим делать

До нас единственным маршрутом для собственника, получившего предписание Россельхознадзора, было — нанять юриста за 50–200 тыс ₽ на анализ ситуации, и ещё столько же на сопровождение. Мы это меняем.

Сервис делает первичную диагностику и подготовку базовых документов доступной для каждого. Только сложные кейсы с реальной ценностью для юриста — отправляются юристу. Это решение и для пользователей (быстрее и дешевле), и для юристов (фокус на сложных делах, где они приносят максимальную ценность).

Принципы

Как мы работаем

1. Приложение, не корпорация

Мы строим продукт, а не разводим штат. Команда — небольшая, сфокусированная. Без лишних регламентов, корпсоглашений и должностных инструкций сверх необходимого.

2. AI-augmented, не AI-replaced

Искусственный интеллект — помощник, не замена. Все процессуальные решения принимает либо собственник, либо аккредитованный юрист с УКЭП. AI делает первый шаг быстрым.

3. Compliance первым

При конфликте между «сделать быстрее» и «соответствовать регуляторике» — побеждает регуляторика. Это не «галочка», а архитектурный выбор с самого начала.

4. Российский стек

YandexGPT 5.1 Pro, GigaChat 2/Ultra, Postgres Pro 17, Astra Linux SE, Yandex Cloud. Без зарубежных провайдеров. Готовность к включению в реестр Минцифры.

5. Privacy by design

Минимум собираемых ПДн. Раздельные согласия по целям. Хеширование чувствительных данных. Удаление аккаунта по запросу за 30 дней. Никакой скрытой телеметрии.

6. Открытость

Документация открыта (КД-пакет ГОСТ 34/19/Р56939). Источники в RAG-базе — публичные. Конструктивная обратная связь от пользователей и юристов — главный двигатель развития.

Май 2027+

Расширение продукта

Технологии

Российский стек 2026 года

Каждый компонент выбран с учётом регуляторики, производительности и зрелости. Без зависимости от иностранных провайдеров.

Backend

Python 3.13 + FastAPI — основной стек. Богатая экосистема для AI/RAG. Кадровая доступность в РФ. Микросервисы в Yandex Managed Kubernetes.

Mobile

React Native 0.83+ — единая кодовая база iOS + Android. Публикация в RuStore (основной канал) + App Store + Google Play. Нативный SDK от банка-партнёра.

База данных

Postgres Pro 17 для prod УЗ-2 (сертифицировано ФСТЭК). Master + sync replica. pgvector для RAG. ClickHouse для аудит-логов.

Облако

Yandex Managed K8s, регион ru-central1. Smart Web Security WAF. DDoS Protection. Object Storage для документов. Astra Linux SE на нодах prod.

AI / LLM

YandexGPT 5.1 Pro и GigaChat 2 / Ultra — A/B routing. Российские LLM в РФ-юрисдикции. Локальные embeddings для приватного контента.

Безопасность

КриптоПро SDK для УКЭП юристов. TLS 1.3+ на всех каналах. mTLS внутри кластера через Linkerd. SAST/DAST в CI.
